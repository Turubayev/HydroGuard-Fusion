## 📌 О проекте
**HydroGuard-Fusion** — аналитическая система раннего обнаружения и локализации утечек в городских водопроводных сетях. Она объединяет (fusion) три источника: датчики давления и расхода, акустические гидрофоны и **гидравлическую модель сети**. Опционально подключаются датчики качества воды для мониторинга рисков загрязнения.

## 🎯 Решаемая проблема
Изношенные сети водоснабжения теряют значительную часть подготовленной воды через скрытые утечки (неучтённые потери). Падения давления при авариях создают риск подсоса загрязнённых грунтовых вод в трубопровод. Раннее обнаружение небольших утечек снижает потери воды, затраты на аварийный ремонт и риски для здоровья населения.

## 🔬 Что система умеет и чего не умеет
| Задача | Источник данных | Статус |
|---|---|---|
| Обнаружение утечки | Давление, расход, акустика | ✅ Основная функция |
| Локализация утечки до участка сети | Несколько гидрофонов (кросс-корреляция) + модель сети | ✅ Основная функция |
| Оценка риска загрязнения | Эпизоды низкого давления + **датчики качества воды** | ⚙️ Только при наличии датчиков качества |
| Обнаружение патогенов | — | ❌ Невозможно по давлению и звуку; требует лабораторного анализа |

> Давление и акустика **не позволяют определить загрязнение воды**. Для мониторинга качества нужны датчики остаточного хлора, мутности, pH и электропроводности. Без них система оценивает только *условия*, при которых загрязнение возможно (например, длительное падение давления).

## 🛠 Стек технологий
* **Анализ временных рядов и DSP:** Python 3.11+, Pandas, NumPy, SciPy
* **Гидравлическое моделирование:** EPANET + WNTR (Water Network Tool for Resilience)
* **Акустика:** Librosa (спектрограммы), кросс-корреляция сигналов (TDOA)
* **ML:** PyTorch (AutoEncoder / LSTM-AE для аномалий), Scikit-Learn (базовые модели и классификация)
* **Поток данных:** MQTT (датчики → шлюз) → Kafka (шлюз → аналитика)
* **Хранение:** TimescaleDB
* **Визуализация:** Grafana / Streamlit + карта сети

## ⚙️ Архитектура
1. **Источники данных.** Синтетический симулятор (на базе WNTR) и открытые бенчмарки; в перспективе — реальные датчики.
2. **Сбор и транспорт.** MQTT для устройств, Kafka для аналитического конвейера.
3. **Обработка сигналов.** Фильтрация городского шума (транспорт, насосы), полосовые фильтры, Мел-спектрограммы.
4. **Обнаружение аномалий.** AutoEncoder, обученный на нормальных режимах; учёт суточного и недельного цикла потребления, чтобы не путать пиковый расход с утечкой.
5. **Локализация.**
   * акустическая: кросс-корреляция сигналов пары гидрофонов → расстояние до утечки;
   * гидравлическая: сравнение реального давления с моделью сети → наиболее вероятные участки.
6. **Оценка риска качества** (опционально): правила и классификатор по данным датчиков качества и эпизодам низкого давления.
7. **Оповещения.** Инцидент с координатами участка, уровнем уверенности и рекомендацией (проверить / выслать бригаду).

## 📚 Данные
| Датасет | Описание | Назначение |
|---|---|---|
| **BattLeDIM 2020** (сеть L-Town) | Открытый бенчмарк обнаружения и локализации утечек | Основное сравнение с другими методами |
| **LeakDB** | Набор сценариев утечек для тестовых сетей | Обучение и валидация |
| Синтетика WNTR | Сценарии с контролируемыми утечками | Обучение AutoEncoder, стресс-тесты |
| Реальные данные водоканала | При наличии партнёрства | Пилот |

## 📏 Метрики
| Метрика | Что измеряет |
|---|---|
| Detection rate / False alarm rate | Доля найденных утечек и ложных тревог |
| Time-to-detection | Время от начала утечки до сигнала |
| Ошибка локализации (м) | Расстояние от предсказанной до реальной точки |
| Минимальный обнаруживаемый расход | Насколько маленькую утечку видит система |
| Оценка по правилам BattLeDIM | Сравнимость с опубликованными результатами |

## 🔐 Кибербезопасность критической инфраструктуры
* Система работает **только в режиме чтения**: не управляет задвижками и насосами.
* Аутентификация устройств (TLS для MQTT), сегментация сети по принципам IEC 62443.
* Подписанные обновления прошивок датчиков.
* Координаты сети и места уязвимостей не публикуются в открытом доступе.

## 🚧 Ограничения
* Акустическая локализация хуже работает на пластиковых трубах (звук затухает быстрее, чем в металле).
* Точность зависит от плотности установки датчиков.
* Модель, обученная на одной сети, требует дообучения для другой.
* Без датчиков качества система не оценивает загрязнение.
